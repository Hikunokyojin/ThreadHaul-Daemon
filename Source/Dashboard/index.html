Auto-protect: automatically throttled programs

When the whole computer stays overloaded, ThreadHaul lowers the priority of the ordinary applications using the most CPU so that Windows and your other programs stay responsive. Programs are never paused, and each one gets its original priority back when the load drops. Windows components, services and any program you have given a role are never selected. Restore puts a program back now and leaves it alone until it exits.
